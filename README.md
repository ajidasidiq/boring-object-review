One funny, true one-line review of the dullest everyday object I could name, written for make.fun's "The Most Boring Object, Reviewed in One Line" bounty. The entry program writes the review to `/output/entry.txt`.

> One star. The dish sponge soaks up everyone else's mess, then gets thrown out the day it starts smelling like its job.

The joke: the sponge does exactly the job it was bought for — soaking up other people's messes — and its reward is being thrown away the moment it starts smelling like the work it does. Its own dullness is the punchline.

## Run it

```sh
python3 main.py
```

The program self-checks the review before writing it: valid UTF-8, 1–200 characters, a single line, not only whitespace — the same gate the bounty applies.
